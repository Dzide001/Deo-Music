# Deo Music v0.1.0

## Installation

### APK (Direct Install)

Download `Deo-Music-v0.1.0.apk` and install directly on your Android device.

**Steps:**

1. Enable "Unknown Sources" in your Android settings
2. Download the APK file
3. Open the APK file on your device to install

### AAB (Google Play Store)

`app-release.aab` is for publishing to Google Play Store. Use this if you're an app developer deploying to production.
